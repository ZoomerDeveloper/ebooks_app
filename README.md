# Epoems - Изучение слов через поэзию

Мобильное приложение для изучения английских слов через поэзию. Доступно на iOS и Android.

## ✨ Особенности

- 📚 **Изучение через контекст** - Учите новые слова в контексте красивых стихов
- 🎨 **Современный дизайн** - Красивый интерфейс с градиентами и анимациями
- 🔐 **Гостевой режим** - Доступ к бесплатным стихам без регистрации
- 💎 **Premium подписка** - Неограниченный доступ ко всем стихам
- 📊 **Статистика** - Отслеживайте свой прогресс обучения
- ⭐ **Избранное** - Сохраняйте любимые стихи
- 🔑 **Несколько способов входа** - Вход по паролю или коду из email

## 🛠 Технологии

- **Flutter** - Кроссплатформенный фреймворк
- **Provider** - State management
- **HTTP** - API клиент
- **Flutter Secure Storage** - Безопасное хранение токенов
- **Google Fonts** - Красивые шрифты
- **URL Launcher** - Открытие ссылок оплаты

## 🚀 Начало работы

### Требования

- Flutter SDK 3.8.1 или выше
- Dart SDK
- Android Studio / Xcode (для соответствующих платформ)

### Установка

1. Клонируйте репозиторий:
```bash
git clone <your-repo-url>
cd epoems
```

2. Установите зависимости:
```bash
flutter pub get
```

3. Настройте URL backend в файле `lib/constants/app_constants.dart`:
```dart
static const String baseUrl = 'http://your-backend-url';
```

4. Запустите приложение:
```bash
flutter run
```

## 📡 API Интеграция

Приложение интегрируется с FastAPI backend:

- `POST /auth/register` - Регистрация
- `POST /auth/login` - Вход по паролю
- `POST /auth/request-code` - Запрос кода на email
- `POST /auth/login-by-code` - Вход по коду
- `GET /config` - Конфигурация приложения
- `GET /poems?letter=A` - Список стихов по букве
- `GET /poems/{id}` - Получить стих
- `GET /search?q=...` - Поиск стихов
- `GET /subscription/status` - Статус подписки
- `GET /stats` - Статистика пользователя
- `POST /payment/create` - Создание платежа
- `GET /favorites` - Избранные стихи
- `POST /favorites` - Добавить в избранное
- `DELETE /favorites/{id}` - Удалить из избранного
