# Epoems - Learn Words Through Poetry

Красивое мобильное приложение для изучения английских слов через стихи. Построено на Flutter с современным дизайном и плавными анимациями.

## 📱 Особенности

### ✨ Дизайн
- Современный Material Design 3
- Градиентные элементы и карточки
- Плавные анимации и переходы
- Адаптивный интерфейс
- Красивая типографика с Google Fonts (Poppins, Inter, Crimson Text)

### 🎯 Функциональность

#### Без регистрации (гостевой режим)
- Просмотр каталога стихов
- Поиск по словам
- Чтение бесплатных стихов
- Просмотр информации о подписке

#### Для авторизованных пользователей
- Регистрация и вход (по паролю или коду из email)
- Добавление стихов в избранное
- Просмотр статистики обучения
- Доступ к платным стихам (с подпиской)
- Оформление Premium-подписки

### State Management
Приложение использует **Provider** для управления состоянием:
- `AuthProvider` - аутентификация и пользователь
- `PoemProvider` - загрузка и поиск стихов
- `AppDataProvider` - подписка, статистика, избранное

## 🔧 Настройка

1. Клонируйте репозиторий
2. Установите зависимости:
```bash
flutter pub get
```

3. Настройте URL backend в файле `lib/constants/app_constants.dart`:
```dart
static const String baseUrl = 'YOUR_BACKEND_URL';
```

4. Запустите приложение:
```bash
flutter run
```

## 🔌 API Endpoints

Приложение интегрируется с FastAPI backend:

### Публичные
- `GET /config` - конфигурация приложения
- `GET /poems?letter=A` - стихи по букве
- `GET /poems/{id}` - конкретный стих
- `GET /search?q=word` - поиск

### Аутентификация
- `POST /auth/register` - регистрация
- `POST /auth/login` - вход
- `POST /auth/request-code` - запрос кода
- `POST /auth/login-by-code` - вход по коду

### Требуют авторизации (JWT)
- `GET /subscription/status` - статус подписки
- `GET /stats` - статистика
- `GET /favorites` - избранное
- `POST /favorites` - добавить в избранное
- `DELETE /favorites/{id}` - удалить из избранного
- `POST /payment/create` - создать платеж

## 🎯 Использование без регистрации

Приложение полностью функционально без регистрации:
- Просмотр каталога
- Поиск стихов
- Чтение бесплатных стихов
- Просмотр информации о Premium

Для доступа к избранному, статистике и платным стихам необходима регистрация.

## 💎 Premium функции

При активной подписке доступны:
- Все стихи без ограничений
- Неограниченное избранное
- Детальная статистика
- Будущие премиум-функции

## 🔐 Безопасность

- JWT токены хранятся в `flutter_secure_storage`
- Автоматический переход на экран входа при ошибке 401
- Проверка подписки для платного контента (403)

## 🌟 Особенности реализации

### Форматирование стихов
Стихи отображаются с учетом токенов:
- `isContext: true` - жирный курсив (контекстное слово)
- `isUppercase: true` - увеличенный размер (выделенный текст)

### Анимации
- Плавное появление Splash Screen
- Переходы между страницами онбординга
- Анимация выбора буквы в каталоге
- Круговая диаграмма прогресса

### UX
- Swipe для удаления из избранного
- Pull-to-refresh (можно добавить)
- Диалоги подтверждения
- Информативные snackbar уведомления
